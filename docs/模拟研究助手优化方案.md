## 1. 新模拟建议（simulation advice）接口契约

- 新建议 `schema_version = "simulation_v2"`。
- `size_tier` 枚举：`small` | `medium` | `large` | `none`（对应 10% / 25% / 50%，hold = none）。
- 配套字段：`size_ratio`（float）、`sizing_basis = "fund_position_value"`、`basis_position_value`、`basis_snapshot_sha256`、`decision_at`（带时区 ISO 8601）、`horizon`（可省略，代码默认 `"unspecified"`，不编造金融期限）。
- `evidence_quality` 枚举 `high/medium/low/unavailable`，与 `confidence` 分开建模。
- 内部 `validated_amount` 继续兼容；**前台新建议不再展示每日精确金额**。
- legacy 建议无新字段 → **不得从 legacy 金额反推 tier**。

## 2. 配置

## 3. 新用户模拟操作（user simulation op）接口契约

- `schema_version = "simulation_v2"`，含 `funding_mode`、`external_cashflow`（正入 / 负出）、`external_cashflow_timing = "end"`、`valuation_status`。
- 买：amount 为持仓净投入，fee 另计；external = amount + fee。
- 卖：amount 为 gross，fee 从 amount 扣除；external = -(amount - fee)。
- 转换：内部金额差计费用，**不计入外部流**。
- dividend / reinvestment / fee：分别记为内部收益 / 成本。
- 无 NAV / units 时明确 `pending` / `unavailable`，**不编造份额**。
- 旧操作标记 `legacy`，不回写。
- 旧现金基金：不删、不自动当资金源；旧绩效缺资金流即不可比，不伪装精确比较。

## 4. 建议冻结与刷新

- 新模拟建议按**首次决策前 snapshot 哈希 + run_date + 基金键**冻结。
- 刷新复用原 basis；过期须新的显式决策周期，不静默重算。
- 零仓基金只允许 hold / watch，需人工建仓。首次建仓继续用户手工输入金额或份额；不能用组合总资产或默认起始资金兜底。

## 5. 状态优先级

- state 优先级：`blocked` > `degraded` > `shadow_only` / `approved`。
- invalid 枚举 fail-closed；原 ticket / debate / former / hard-gate 规则保持最严。

## 6. RAG API

- `decision_at` 作为 RAG API **可选参数**（timezone-aware ISO 8601，如 `2026-05-20T10:00:00+08:00`）。
- 仅 date-only 调用明确标记 `end_of_day_legacy`，不宣称盘中无未来数据。
- 有 `decision_at` 时按 offset 截断。
